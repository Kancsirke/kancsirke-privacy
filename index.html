Privacy Policy

Kancsirke Live Chat Translator · Version 1.9.4 · Updated November 14, 2026
Summary: Kancsirke reads chat messages on the supported live-streaming sites to translate them. Text you choose to translate is sent over HTTPS to the external translation service you select. Provider API keys, settings, local usage statistics and optional cached translations are stored in your browser profile. The publisher does not operate a server that receives your chat translations.

1. Purpose and scope

Kancsirke Live Chat Translator is a browser extension that translates incoming live chat and, if enabled, outgoing messages on supported streaming sites. Access to YouTube Live and Kick is optional and requested through browser site permissions. The extension's features are intended for translating messages, improving presentation and controlling the translation workflow.

2. Information handled

  • Website and chat content: visible incoming chat messages, including any usernames or other personal information included in the message text, and outgoing text when you request outgoing translation. The extension accesses the specific message content needed for the translation feature.
  • Selected site and channel context: the current supported chat platform and channel/page URL may be kept locally to identify the current chat and apply saved channel settings. The extension does not use the browser history permission to collect your general browsing history.
  • Provider authentication: optional API keys supplied by you for translation services. These keys are saved with Chrome's browser-local extension storage and are sent only as needed to authenticate requests to the corresponding provider. API keys are not included in normal settings exports.
  • Local configuration: selected languages, display mode, provider choice, optional platform permissions, chat/game profile, glossary, per-channel preferences and other settings. Preferences may use Chrome's optional built-in synchronization, according to the relevant browser settings.
  • Local translation information: optional translated-text cache, request counters, queue status, errors, quota estimates and other extension diagnostics. When caching is enabled, source text and translated text can be saved locally for reuse. Aggregate transport diagnostics are designed not to retain chat text or API keys.

3. External translation services

When translation is enabled, the extension sends the text requiring translation, requested source/target language and technical request details directly to the selected third-party translation endpoint using HTTPS. In keyless mode, text is sent to a Google translation endpoint. If you select Gemini AI, text is sent to Google's Gemini API, authenticated with the API key you provided. Other optional providers, including DeepL and Google Cloud Translation, receive text and your corresponding credentials only when you choose those modes.

When an AI-to-Google fallback option is enabled, text may also be sent to the Google translation endpoint if the selected AI service is unavailable or rate-limited. These services operate under their own privacy policies, retention practices, usage limits and any applicable charges. The publisher cannot control how a chosen third-party provider processes submitted text. Avoid translating sensitive private messages unless you are comfortable sending that text to the selected service.

4. How information is used

Message content is used to return translations and support presentation, caching, terminology rules or manual AI actions. Local diagnostic counters help display rate-limit and queue information, not advertising profiles. The publisher does not sell user data, does not operate a backend receiving translated chat content, and has not added behavioral advertising or third-party analytics to the extension.

5. Limited Use commitment

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information accessed through this extension is used only to provide or improve its disclosed translation functionality and closely related operations. It is not used for personalized advertising, sold to data brokers, or transferred to third parties except as needed to deliver the translation you request or as otherwise permitted under that policy.

6. Storage, security and retention

Connection requests to external translation services use HTTPS. Provider keys and local preferences are handled through browser extension storage. Local storage is controlled by your device and Chrome profile; it is not a substitute for a dedicated encrypted password vault. Cached translations and diagnostics can persist in the browser until they expire, are cleared using available extension controls, or are removed with the extension/profile. Streaming chat elements that remain on a web page are also subject to the streaming site's own behavior and retention.

The publisher does not set a separate retention period for data held by external translation providers. Consult those providers directly for their policies. Browser synchronization, if enabled for non-secret preferences, follows your Chrome settings.

7. Your choices

  • Use keyless translation without providing an AI API key, or select an optional provider yourself.
  • Enable or disable the extension and choose when outgoing messages are translated.
  • Grant or revoke optional YouTube Live and Kick access in Chrome's extension controls.
  • Turn translation caching on or off, clear supported cached data and reset local statistics in the extension.
  • Remove stored keys in extension settings, remove the extension or clear its browser storage to remove locally stored data. Browser-synced preferences may require clearing Chrome synchronization separately.

8. Children, platform content and trademarks

The extension is not designed to gather information about children. It translates content displayed in third-party live chats, and does not control what chat participants write. Kancsirke is an independent extension, not an official product of or endorsed by any streaming platform or translation provider.

9. Changes and contact

This policy may be updated when the extension or its data practices change. The current version will be published at this URL. For questions, contact the publisher through the Chrome Web Store listing's publisher/support information.
