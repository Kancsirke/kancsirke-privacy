Privacy Policy — Kancsirke Live Chat Translator

Effective date: October 20, 2026

Kancsirke Live Chat Translator (the “Extension”) provides translation and associated language/readability tools for Twitch chat and optional YouTube Live and Kick chat. This policy describes its data practices.

1. Developer-controlled data collection

Kancsirke does not operate a translation backend, user-account server, telemetry collector or advertisement system for this Extension. The developer does not receive chat logs, API keys, local statistics, glossary entries or browsing history on a Kancsirke server. The Extension does not sell user data or use it for unrelated advertising or profiling. The Extension uses information received from Chrome and Google APIs in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

2. Website access

The Extension can read visible Twitch chat and chat input on Twitch pages to provide translation. YouTube Live and Kick chat access is optional: the Extension only requests the respective site permission when the user explicitly enables that platform in settings. It does not need access to unrelated websites or a complete browsing-history list. To recognize the current channel and apply channel-specific profiles, the Extension locally stores the active supported livestream page URL, channel identifier and platform/scope. It does not send this active-channel record to a Kancsirke server. All three platforms' chat layouts can change over time.

3. Text sent to translation providers

When translation is enabled, chat text necessary for the translation is sent directly from the browser to the selected translation provider: keyless Google Translate, Google Cloud Translation, Google Gemini, or DeepL. Text entered into supported chat input fields may also be sent for translation when the user activates outgoing translation. Gemini manual polish and slang-explanation buttons send the clicked source message and any existing translation to Gemini only when the user clicks them.

Those third parties have their own terms, privacy policies, rate limits and data retention practices. Some provider features may require an API key or paid plan.

4. API credentials

User-supplied Gemini, Google Cloud Translation and DeepL API credentials are stored in Chrome local extension storage, not transmitted to a Kancsirke backend, and are excluded from settings exports. The credentials are sent only to the respective external service as needed for authenticated requests. Users should keep keys private and rotate keys if exposed.

5. Local settings and storage

The Extension stores user preferences, supported platform enablement, UI language and layout, glossary entries, channel profiles, the currently active supported livestream URL/channel identifier, mention keywords, cached translations, local usage statistics and temporary Gemini rate/cooldown state in Chrome extension storage and/or IndexedDB. Duplicate-spam detection and mention matching happen locally. There is no developer analytics upload. Local statistics can be reset and translation cache cleared from the popup. Cached translations expire according to user-selected TTL/LRU rules. Other settings remain until changed or the Extension is removed.

6. Optional site permissions

  • Twitch chat: https://*.twitch.tv/* (available at installation).
  • YouTube Live chat: https://*.youtube.com/* (opt-in).
  • Kick chat: https://*.kick.com/* (opt-in).

Optional permissions are requested after the user turns on the corresponding platform. The Extension may register and unregister the related site-specific content script; disabling a platform removes its optional permission where supported by Chrome. This is not permission to scan general browsing history.

7. Settings synchronization and import/export

Non-secret options may use Chrome Sync under the user's Chrome/Google account settings. API keys stay in local extension storage. Settings exports are created only after user action and exclude API keys. Importing a settings file does not automatically grant new site permissions.

8. Data retention and security

No Extension data is retained on a developer-controlled server. Locally stored data persists until expired, cleared or removed according to the browser and the Extension's settings. Google and DeepL may retain submitted text according to their own policies and the account tier used. HTTPS is used for translation endpoints. Anyone with sufficient access to the browser profile or extension debugging environment may be able to inspect locally stored credentials.

9. Children

This general-purpose chat translation tool is not directed specifically to children. It does not knowingly collect children's personal information on a Kancsirke server.

10. Updates and contact

Material changes to data practices will be disclosed in an updated policy and store listing. Project support and contact route: https://ko-fi.com/kancsirke.
